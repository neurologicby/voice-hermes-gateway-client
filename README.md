# VoiceGateway Windows client

Открытый Windows-клиент для голосового WebSocket-шлюза Hermes: PySide6 UI,
локальный wake word/VAD, захват и воспроизведение PCM, barge-in, drag-and-drop
файлов и локальная SQLite-история.

Клиент реализует protocol v1 самостоятельно и не импортирует код серверного
плагина во время выполнения.

Каждый бинарный аудиофрейм содержит 8-байтовый big-endian `seq`, за которым
следует PCM S16LE mono 16 kHz. Это позволяет отбрасывать запоздавшие чанки
после `interrupt` или начала новой реплики.

## Запуск из PyCharm

Выберите общий `.venv` рабочей папки как interpreter и укажите модуль запуска
`voice_client.app`. Эквивалентная команда из корня `VoiceGateway`:

```powershell
.\.venv\Scripts\python.exe -m voice_client.app
```

При первом запуске клиент сохраняет постоянный device UUID. Для отправки голоса
удерживайте кнопку «Говорить»; русский или английский язык выбирается явно перед
началом реплики. Микрофон и динамик выбираются в окне и сохраняются между
запусками. Файлы размером до 50 МБ можно перетащить в пунктирную область — чтение
и отправка выполняются вне UI thread.

## Локальный wake word

Wake-контур реализован независимой state machine: в `sleep` PCM обрабатывает только
локальный движок, и до trigger ни один фоновый чанк не попадает в WebSocket. После
trigger начинается новый `audio_start`; mute и pause сбрасывают decoder state и
блокируют как детекцию, так и отправку.

Для произвольных RU/EN фраз используется `SherpaPhraseWakeEngine` поверх локальных
streaming ASR-моделей с явной открытой лицензией. Официальные KWS-веса sherpa-onnx
пока не включаются: готовой RU-модели нет, а лицензия опубликованных KWS-весов не
указана отдельно. Модели не скачиваются при старте UI.
